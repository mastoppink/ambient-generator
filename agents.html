1. Purpose

The app creates still background images and long looping videos for ambient / dark-ambient music (YouTube, 16:9). Aesthetic: kenopsia, megalophobia, liminal space; a lone, original, abandoned structure in a vast, quiet, hazy landscape; photorealistic; no life.

  • Prompt Generator (./): builds narrative image prompts for Nano Banana (Google Gemini image models).
  • Video Studio (./studio.html): upscales the image to 4K, color-grades it, adds animated overlays, and renders an MP4 for the full audio length, entirely in the browser (Remotion web renderer).

2. End-to-end workflow

  1. Open the generator with the audio title: ./?title=<audio title> (or pick options manually).
  2. Copy the prompt → generate in Nano Banana (Gemini). Generate 3–4 variants, keep the best.
  3. If something is off, send a revision prompt in the same Gemini chat.
  4. Click Buka Video Studio (passes overlay settings via ?cfg=).
  5. In the Studio: choose image → Upscale ke 4K → pick a color grading preset → adjust overlays → choose audio → Render Video.

Image generation and file selection need a human (or an agent with browser + file access). The generator itself needs no login and no API key.

3. Prompt generator: concepts

4. URL API

Every state is in the URL, so an agent can create shareable, reproducible links.

ParamValue
titleAudio title. Overrides everything: the generator detects landscape, mood, details and mood sentences. Same title → same result.
l, mlandscape id, mood id
s o g c windex of structure, foreground, lighting, framing, twist (0-based, see options.json)
d a edot-separated indexes of decay, atmosphere, emptiness, e.g. d=0.2
ar t st xaspect, title space (1/0), style (photo/matte), extra sentence
./?title=Ruang%20Hampa%20%C2%B7%20Musik%20Ambient%20Muram%20untuk%20Tidur
./?l=frozen&m=megalophobia&s=3&c=5&w=2&g=1&d=0&a=2&e=1&ar=16:9&t=1&st=photo
./studio.html?cfg=<base64 of UTF-8 JSON, see §9>

5. Building a prompt yourself (no browser needed)

Read agent/options.json and join these sentences in order (skip empty ones). Target length 1,300–1,800 characters.

1  {mood.camera}                      ({L} → landscape.landscape)
2  Subject: a lone {structure}, {ORIGINAL}, {decay}.
3  Unexpected detail: {twist}.         (skip if twist is "")
4  Composition: {framing.text}
5  Foreground: {foreground}, sparse and understated.   (skip if framing.fg === false)
6  {landscape.medium}.
7  Air: {atmosphere}; light: {lighting}.
8  {GLOW}
9  {INTEGRATE}
10 Palette: {landscape.palette}.
11 Generous empty space, {emptiness}.
12 {mood.feeling}
13 {DESERTED}
14 {STYLES.photo.text | STYLES.matte.text}
15 {TITLE_SPACE}                       (optional)
16 {extra}                             (optional)
17 16:9 landscape format.

Multiple values in one field are joined as a, b and c.

6. Title → prompt

Keyword rules (English + Indonesian) map an audio title to settings. Multi-word phrases are matched first (“deep space” is not “deep” + “space”).

GroupExamples → effect
Landscape wordsocean/laut → abyssal · sand/gurun → desert · snow/salju → frozen · fog/hutan → forest · planet/bintang → alien · city/lorong → urban · salt/cermin → saltflat · ash/lava → volcanic · lighthouse/pantai → coast · cave/gua → cavern
Space imageryaurora, nebula, starlight, galaxy, orbit, celestial sea → a sky sentence over any landscape; deep space / void / event horizon / far side of the moon → alien landscape
Modes (Lydian…Phrygian)weightless/melayang → bright · serene/tenang → calm · wistful/sendu → kenopsia, warm tint · dark/muram → dark · mysterious/misterius → megalophobia, dark
Brightnessshimmering/berkilau → brighter · deep/dim/pekat → darker (a light sentence is added when clearly bright/dark)
Melodyglass bells → glints of light · kalimba → droplets of light · piano → intimate stillness · drones → unbroken fog
Purposesleep/tidur → darker, solitude · focus/fokus → orderly · study/belajar → steady · meditation/meditasi → still reflection
Shape & chaptersslowly unfolding, arrival, drift, afterglow, nightfall, horizon… → matching sentences
Banned432, 528, Hz, binaural, healing, theta, solfeggio, no ads, cure, miracle, dna… are ignored

Up to 4 mood sentences (+1 light sentence) go into the extra field. The title text itself is never put in the image prompt (so the image contains no text).

7. Revision prompts

Follow-up messages for the same Gemini chat, to fix an image without regenerating. Format:

Edit this image. Keep the composition, subject, style and mood the same, and only change the following: {fix 1} {fix 2} …

Fixes available (see revisions in options.json): miniature look, pasted-in look, subject too small / too large, too cluttered, too bright / too dark, colors too strong, more / less haze, looks like a famous landmark, not realistic enough, odd objects, more title space.

8. Overlay & motion

The generator proposes overlays per landscape (fog color/opacity, particle kind, stars, aurora, god rays, grain, vignette, slow zoom, light “breathing”), adjusted by the extra sentences (rain, snow, stars, aurora, dark). It also gives two separate Nano Banana prompts for overlay assets on pure black (fog; particles) for use in other editors with Screen blending. Nano Banana makes one image per prompt, so they are separate.

9. Video Studio

  1. Image: PNG/JPG/WEBP.
  2. Upscale ke 4K: Real-ESRGAN in the browser (ONNX Runtime Web; WebGPU, CPU fallback). max = x4plus (most detail, 67 MB, needs a GPU); fast = General x4v3 dn0.3 (5 MB). Always re-runs from the original image. Output 3840×2160.
  3. Color grading: 10 presets (default chosen by landscape) + intensity + manual exposure, contrast, saturation, temperature, tint, fade, split toning. Applied to the image pixels once; preview = render.
  4. Overlay: fog, particles (snow, rain, dust, sediment, stardust, sparkle), stars, aurora, god rays, grain, vignette, zoom, breathe. All motion is periodic so the loop is seamless.
  5. Resolution: 1080p, 1440p, 4K (default). File quality: high (YouTube upload recommendation, 4K 40 Mbps), balanced (default, 4K 16 Mbps), small (4K 8 Mbps); estimated size shown. Loop length: 10–60 s (default 20).
  6. Render: renders only the loop, then repeats it for the full audio length without re-encoding and adds the audio (MP3/M4A copied; WAV/FLAC → AAC 256/192 kbps). Writes straight to disk via the save dialog.

cfg JSON (base64 of UTF-8 in studio.html?cfg=):

{ "width": 1920, "height": 1080, "fps": 30, "scale": 2, "loopSeconds": 30, "landscape": "frozen",
  "overlays": { "fog": { "color": "#e8eff3", "opacity": 0.28 }, "particles": { "kind": "snow", "count": 220 },
                "stars": false, "aurora": false, "rays": false,
                "grain": 0.05, "vignette": 0.35, "zoom": 0.04, "breathe": 0.03 } }

Requirements: Chrome or Edge on desktop (WebCodecs, File System Access). Everything runs locally; nothing is uploaded.

11. Rules & limits

  • Nano Banana prompt length: no official character limit; input is limited in tokens (65,536 for Nano Banana Pro). Long prompts reduce adherence, so keep prompts around 1,300–1,800 characters. The generator warns above 2,000.
  • No negative-prompt field in Nano Banana: exclusions are written as sentences (DESERTED).
  • Never depict real or famous landmarks, people, animals, vehicles, lights, text or watermarks.
  • Keep the subject readable (about a third of the frame by default) with true monumental scale; avoid miniature/tilt-shift looks.
  • Remotion is free only for individuals and companies of up to 3 employees; others need a license (remotion.dev/license).
  • Real-ESRGAN models: BSD-3-Clause (see models/README.md).
